Upgrade-Werkstatt

Bitcoin hat keinen Chef, der Updates verteilt. Jede Node entscheidet selbst, ob sie neue Regeln übernimmt. Das nennt man einen Fork, eine Gabelung.

Spiel ein Upgrade durch

Soft Fork: Die Regeln werden strenger. Alte Nodes akzeptieren die neuen Blöcke trotzdem. Alle bleiben zusammen.
Hard Fork: Die Regeln werden lockerer. Alte Nodes lehnen die neuen Blöcke ab. Die Kette kann sich spalten.

    Kein ZwangNiemand kann ein Update erzwingen. Jede Node wählt selbst, welche Software sie nutzt.
    Soft ForkStrengere Regeln, abwärtskompatibel. So kamen SegWit und Taproot. Bitcoin bevorzugt diesen Weg.
    Hard ForkLockerere Regeln. Machen nicht alle mit, entstehen zwei Coins. So entstand Bitcoin Cash.
    Langsam ist AbsichtUpgrades brauchen Jahre an Diskussion und meist über 90 % Zustimmung. Das schützt vor Fehlern.
